# 决策记录 0028：中文单语页自报语言，站点说明页移入页脚

Status: implemented
Class: feature

## Problem

站内有三页只有中文正文：`/formulas`（战斗公式）、`/architecture`（项目架构）、`/about`（数据说明）。
其余页面随展示语言切换，这三页不切，于是暴露三个问题：

1. **根语言说谎。** `useLocale` 的 `applyHtmlLang` 按展示语言写 `<html lang>`：英文读者读到的
   `<html lang="en">` 包里装的是中文正文。读屏按英文音系朗读；浏览器据此认定「页面已是这个语言」，
   因而**不提示翻译**——这条既是 WCAG 3.1.2（Language of Parts），也是「英文读者点进来看到一页看不懂的字」
   的真实来源。页内那条「本页仅中文」注记解决不了它。
2. **入口不预告。** 导航与目录只印板块名（且板块名是四语的，读起来像英文本地化页面），
   读者点进去才知道正文只有中文。注记挂在页内，等于事后告知。
3. **首页目录混了两类东西。** 「项目架构」「数据说明」讲的是站点自身与数据出处，与四个游戏类目并排编号
   07 / 08；而页脚（数据源、版本、日期、版权）本来就承载「这个站是什么、数据从哪来」。
   目录该是档案索引，不该兼作站点说明的入口。

## Decision

1. **根语言按正文报真话。** `useChinesePageLang()`（`composables/useLocale.ts`）在这三页挂载时把
   `<html lang>` 覆写为 `zh-CN`，卸载时还原为那一刻的展示语言；三页的正文与界面外壳因此各报各的语言。
2. **语言说明只在页内。** 页面顶部保留 `longform.chineseOnly` 注记（非中文界面才渲染），
   入口（首页目录、页脚、站头导航）**不挂**语言标——试过一版又撤掉，见 Alternatives。
3. **站点说明页移出目录，改由页脚进入。** `domain/catalog.ts` 拆出 `SITE_INFO_ENTRIES`
   （项目架构、数据说明，只有四语名与路径）：不进首页目录、不进站头导航，
   由 `SiteFooter` 派生链接。首页目录收为 01–06（四个类目 + 战斗公式 + 设置），编号仍连续。
   路由标题改由 `guideForPath()` 取，它同时覆盖 `GUIDE_ENTRIES` 与 `SITE_INFO_ENTRIES`。

## Alternatives considered

- **按展示语言隐藏这三页**（非中文界面下不渲染 / 落到 404）：链接必须永远有内容——中文社区发出的
  `/formulas` 被英文读者打开会变成空页；隐藏只能藏前端，sitemap 与逐路由静态 HTML 仍是中文单一集合，
  搜索引擎照抓；读者正在读这三页时切换语言，页面会当场消失。要按语言裁剪页面，正确位置是
  「语言进 URL」之后的构建期 URL 集（见 0010 的遗留缺口），不是客户端 `v-if`。
- **在入口挂「仅中文」标**（首页目录行与页脚链接各挂一枚小签）：做过一版
  并撤掉——页脚两枚相邻的「Chinese only」把注意力从台账上抢走，首页目录那枚又与名称的拉丁铭牌挤在同一行；
  入口不预告语言的缺口由此留着，说明只放页内那条注记。
- **把标记放进站头导航**：0004 的空间账里 en 的主排导航单行需 583px，断点 1000 已按最长语言取整；
  「仅中文」至少再加 20px，1000–1023 在 en 下会横向溢出。加它必须把断点抬到 1024 并重测四语，
  收益与改动不成比例。
- **只给正文容器加 `lang="zh-CN"`**：更贴合 3.1.2 逐段标记的字面，但浏览器翻译提示与读屏判定都看根语言，
  标在正文容器上等于不生效。
- **保留「页脚只放台账」的原取舍**（0027 与 `docs/conventions/contracts.md` 原有规则）：页脚曾是
  数据源 / 版本 / 日期 / 版权的台账，不加第二条链接的理由是「手写链接会与类目表各存一份文案，改文案必漏一处」。
  本次链接改为**从 `SITE_INFO_ENTRIES` 派生**，这条理由消失；页脚语义按「这个站是什么」扩展。

## Consequences

- 收益：非中文读者在这三页能触发浏览器翻译，读屏音系正确；页内注记仍逐页说明「本页仅中文」。
- 收益：首页目录只列游戏内容与本机偏好，01–06 编号连续；两个说明页从档案目录移到站点台账，语义归位。
- 代价：入口不预告语言（入口标做过又撤掉，见 Alternatives），读者仍要点进去才看到那条注记。
- 代价：项目架构页原先占首页目录第 07 项，现在唯一入口是页脚，发现面变小。
- 代价：`docs/conventions/contracts.md` 的入口规则与 0027 的页脚取舍被本记录改写（已双向互链）。
- 遗留缺口：`/about` 与 `/architecture` 的拉丁铭牌（`COLOPHON` / `ARCHITECTURE`）随条目移出
  `GUIDE_ENTRIES` 一并删除，页脚只显示四语名；若页脚需要铭牌，要在 `SITE_INFO_ENTRIES` 里补 `en` 字段。

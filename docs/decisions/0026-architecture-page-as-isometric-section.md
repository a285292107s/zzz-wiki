# 决策记录 0026：项目架构页用「等距剖面块」表示分层

Status: implemented

Class: feature

> 已被 [0027](./0027-architecture-page-as-zoomable-atlas.md) 取代：这一页现在只剩一张可缩放的系统地图，
> 本记录描述的装置已随重构删除，保留它是为了记住当时的取舍。


## Problem

站点的代码分层（页面 / 交互 / 展示 / 规则 / 取数 / 工具 / 藏品）此前只写在仓库文档里
（[`docs/architecture.md`](../architecture.md)、[`DESIGN.md`](../../DESIGN.md) §4.1），读者与协作者
都得去翻文件。要把它做成图上的一件东西，有三个难点：

1. **分层是堆叠关系，不是流程。** 站点已有的等距台阶（[0025](./0025-pipeline-page-as-isometric-stair.md)）
   表达的是「一路向下」的流向；照它画层，会把「结构」读成「流程」。
2. **七层各自要能被指认**（层号、名称、职责、边界），可等距斜面上的文字跟着斜面倾斜就不可读，
   站内也不允许把信息性文字画进 SVG。
3. **与链路图同页出现，不能撞脸。** 两张图若用同一种立体装置，整页会像同一张图放了两遍。

## Decision

新增「七层剖面」图：**一块有厚度的等距剖面块**。顶面（屋面）上放一张小薄板，画成「页面」的样子
（三条字行）——顶层产物是一张页面，画的正是它；两个可见立面被剖成 **7 条地层带**，一条一层，
带与带交替两档面色，读作地层；层号用 SVG 里的小号数字压在地层上（纯装饰、`aria-hidden`），
层名、职责与边界在右侧标注列。

- **几何仍是纯函数。** `src/utils/isoBlock.ts` 的 `layoutBlock` 按容器宽反解跨度、层带高、屋面、
  页面板、七条引线锚点与画布高。仍然是「SVG 画几何 + HTML 覆盖文字」，没有 3D 库、没有 canvas。
- **交互比链路图更克制。** 没有「走一遍」——分层不是序列。悬停 / 聚焦 / 点击任一行 → 对应那一层
  两个立面同时亮起、层号转琥珀、引线转琥珀；入场时七层自下而上错峰 55ms 浮起。全部在
  `prefers-reduced-motion: reduce` 下退化为静态。
- **一页两张图，各管一件事**：图 01 剖面块 = 结构（谁在谁上面），图 02 台阶 = 流向（数据怎么下来）；
  两图之后各跟一张台账（七层清单 / 六层台账），区块编号连续。
- **窄屏换装置，不缩图**：<900px 换成竖排小台阶，与链路图共用 `components/iso/IsoColumn.vue`
  （行数据由视图映射：层 → 号 / 名 / 一句 / 路径）。
- **分层事实单一事实源 = `src/domain/architecture.ts`**：七层的 `path` / `brief` / `role` / `edge`。

## Alternatives considered

- **七块平板垂直堆叠（经典 layered diagram）。** 同一 footprint 在等距投影下每块都会被上一块遮掉
  大半，要露出七块就得多给六段行高，画布会被推到 1000px 以上；缩小间距又只剩薄边、放不下字。否决。
- **七级阶梯（逐级后退的 ziggurat）。** 每层都有可见台面、也很好看，但它与下方的链路图（台阶）
  几乎同构，一页会出现两张「楼梯」。否决。
- **复用链路图的装置、只换数据。** 语义错：分层没有时间方向，把层画成「一级级往下走」会把结构
  读成流程。否决。
- **立方体不剖、层名贴在斜面上。** 文字必须跟着斜面倾斜（站内不允许），或全部丢到标注列——
  那样图就只剩一个空盒子。否决。
- **画成二维层级框图（方框 + 箭头）。** 无纵深，且站内账册/表格已经是这个语气，再来一张方框图
  只是换了形状的清单。否决。
- **层号也放进标注列、剖面里留空。** 把层号压在地层上，是「图能自己认人」的关键：不看右列也知道
  哪一条是哪一层。沿用链路图的台阶编号做法。否决。

## Consequences

- 代价：多一个懒加载页 chunk 与一套几何/组件（`utils/isoBlock.ts` + `components/iso/ArchBlock.vue`）；
  七层的职责与边界现在有两处表述（给维护者的 `docs/architecture.md` 与给人读的
  `src/domain/architecture.ts`），改分层必须同时改，否则图会与文档漂移。
- 收益：分层第一次有了形状——七层在一屏里可数、可指认，点哪层亮哪层；与链路图共享同一套面色分档、
  点线引线与两位编号，两图并列也读得顺。
- 遗留缺口：实测的依赖边（含数处已登记回跳）**没有画进剖面**——纵深只表达「层」，横向依赖仍靠
  文字注记（「层与层之间不是单向的」）；「楼外三样」（路由表 / 指令 / 样式令牌）同样只在注记里点名。
- 陷阱：屋面是**顶层（页面）的顶面**，不是「结构层」；页面板画在屋面上只是提示「顶层产物是一张
  页面」，不要据此以为页面层在剖面之外——层号 01 就在屋面正下方那条地层带上。

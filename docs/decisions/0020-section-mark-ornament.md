# 决策记录 0020：区块分隔改用雕刻式 SVG 花饰

Status: implemented
Class: feature

## Problem

0018 把边界从区块头挪到空隙中线，用一条金色短刻线（80px、60% 不透明、两端渐隐）。它解决了
"两条线挨得很近"与"线压在标题上"，但读起来仍是一段**孤立的金色短线**：不像档案纸上的章节饰线，
更像一条没画完的分隔线；长页重复出现时偏"占位"。用户提供了维多利亚式卷草分隔线参考
（中轴花冠 + 长引线 + 端部涡卷 + 珠点），要求改成有装饰属性的 SVG 分割线。

## Decision

- 分隔由 `SectionMark`（inline SVG，`aria-hidden`、不占流）承担：一条 1px 基线（在中饰处断开、
  由珠点接住），中轴一枚菱形花芯、两侧对称 **C 形单卷**（不是多圈螺旋）、卷草外各一枚小菱形珠，
  两端各一个涡卷收头——即参考图的"基线 + 中饰 + 端饰"，收进 1px 发丝线。
- 位置不变：空隙中线水平居中（`top: calc(var(--space-section) / -2)`；首页「今日角色」之上
  空的是 hero 的 `--pad-section`，该处在 `HomeView` 覆写偏移）。
- 尺寸 `width: clamp(200px, 32vw, 440px)`（1440 下实宽约 387px）：长于 0018 的短刻线，但短于版心、
  两侧留白——不回到全宽边框线，避免与上一区块的收尾线成对。初版中饰用多圈螺旋，对照用户提供的
  mock 后改为单卷 C 形 + 珠点：卷草更轻、中饰更像"花冠"而不是"眼睛"。
- **双色**：笔画（基线 / 卷草 / 端涡卷）用 `color-mix(in srgb, var(--ink-2) 65%, transparent)`
  （对纸底约 3:1：比表格发丝线亮一档、明显低于正文）；中轴菱形与两枚珠点保留
  `color-mix(in srgb, var(--amber) 72%, transparent)`（约 5:1）。金色是站内的**信号色**
  （区块编号、当前项、关键数字），整条线用金等于把装饰抬到信号的重量；收进花芯后，页面上
  金色的量只剩约 50px，章节信号仍在，但长线退回「墨刻」。
- 线宽 1px 且 `vector-effect: non-scaling-stroke`，随视口缩放时发丝不随之变粗变细。
- 高对比度模式：笔画与花芯一律 `stroke: CanvasText`（系统强制色接管，不看色相）；打印态笔画
  恢复实色墨灰、花芯恢复实色深琥珀（半透明落纸会淡到丢失）。
- 审计同步：`composition-audit` 的 `headRule` 改判 `.section-mark` 存在、是窄带（8–40px 高）、
  宽 120px–头部 80%、水平居中、`aria-hidden`；`forced-colors` 改读元素 `color`（≠ 画布色）。

## Alternatives considered

- **保持 0018 的短刻线**：干净，但用户明确要"装饰属性"，一条短横线没有被继续打磨的空间。
- **参考图原样：全宽连续线 + 两端收头**：全宽线会重新与上一区块的收尾线成对，回到 0017 的坑。
- **1.5–2px 粗描卷草**：更接近参考图，但与站内「1px 发丝线」的语言打架，暗底上会变成发光金线，
  等于把上一轮"存在感太强"的问题放大。
- **更繁复的珠链/多层花冠**：1x 屏上糊成噪点；只保留"一条基线 + 四处涡卷 + 一枚菱形"的
  最低可辨识结构。
- **用花饰字体字符（fleuron 字形）排版**：字体覆盖不可控（本站 CJK 字体分片不含这些字形），
  跨语种会掉字形；几何路径只有一个事实源。

## Consequences

- 收益：章节边界从"孤立的线"变成纸面上的雕刻饰线，与档案语言（细线、编号、暗底）同调；
  长页重复出现时是稳定的"起笔"记号。花饰是一个组件，首页与详情页共用同一套语法。
- 代价：装饰元素变多（4 处涡卷 + 菱形 + 两条镜像路径），且 path 是采样生成后定稿的静态几何
  （不再保留生成脚本，改形状要重算路径）；1x 屏上墨线偏淡（65% × 1px），高 DPR 下最清晰。
  双色意味着「花饰」有两种墨色，改动时别把中饰与笔画写成同一色（会又回到整条金线）。
- 遗留缺口：若日后要更强的装饰性，优先加"珠点 / 端部小菱形"这类点状元素，不要加粗线
  （加粗会与「1px 发丝线」口径冲突）。

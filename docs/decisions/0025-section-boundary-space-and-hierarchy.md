# 决策记录 0025：区块边界退回「留白 + 层级」，花饰与点线引导退场

Status: implemented
Class: design

## Problem

0020 的雕刻花饰是照着「要装饰属性」的参考图做出来的：维多利亚式卷草 + 中轴花冠 + 端部涡卷。
落地后它与站点定位打架——本站的语言是**二十世纪技术档案**（等宽编号、发丝线表格、纸纹、首字下沉、
边缘注记），卷草是**十九世纪书籍装帧**。两种语汇同处一屏时，读者先看见「装饰」，再看见「章节」。

形态之外还有三处结构性不成立：

- **轴线不同源**：全页排版是左对齐（编号列、正文、表格都挂在同一条左缘），只有花饰水平居中——
  它是页面上唯一一条居中轴线，读作外来件而不是边界。
- **亮度两头不靠**：1x 屏上 `--ink-2` 65% × 1px 的基线，淡到不成为「记号」；要它成为记号就得提亮，
  一提亮就抢 36px 标题。0020「装饰不得亮过正文」的校准把它钉在了「看不见」与「抢戏」之间。
- **层级本身太扁**：区块标题 24px vs 正文 15px（1.6×），边界靠一条贯穿 1008px 的点线把标题与
  右端英文注记连起来。点线是**目录行**的器件（把相距很远的两端连起来），章节头里没有要连的东西，
  它是填空。0024 把花饰降到单页 ≤2 之后，剩下的两条既没有换册之外的信息，也没有页内节拍的作用。

用户判断：「那条装饰性分割线，感觉和项目定位不符」。

## Decision

- **撤掉装饰件本身**：删除 `SectionMark`（组件 + 首页两处 / 详情页 `.seam` 条件的全部挂载）、
  删除 `.section-head .leader` 点线，以及只为它们服务的 `--section-gap` 位置声明与首页覆写。
- **边界回到三件信息性器件**：留白（@1440 常规 112px / 换册 157px）、标题字号层级、
  与左侧索引同源的编号。三者缺一不可，标题由此从 `--fs-hero` 24px 提到新令牌 `--fs-section`
  （`clamp(26px, 2.6vw, 36px)`；桌面 36，对正文 2.4×）。
- **换册处只留一条齐版心细线**：`.block.seam .section-head` 取 `border-top: var(--rule)` +
  `padding-top: clamp(20px, 2vw, 28px)`，画在区块头自己的上缘，读作「新一册的起边」——
  与内容胶囊边线、页头下缘线同一口径。`.seam` 的落点与「单页 ≤2、只用于 ≥3 区块页面」不变（0024）。
  首块紧贴页头时不再叠第二条线。
- **区块头三件同轴**：13px 琥珀等宽编号（`align-self: center`）+ 36px 宋体标题 +
  10px 等宽英文分类码右端（`align-self: center`、`margin-left: auto`）。编号从 12px 提到 13px，
  是因为 12px 在 36px 标题旁读作下标；英文注记不再画连接线，两端对齐自身成立。
- `--space-head-body` 28 → 32px（标题变大后需要的呼吸量），`--fs-title` 的注释语义修正为
  「小节 / 面板标题」（它一直不是区块标题，区块标题此前误用 `--fs-hero`）。
- 顺带撤掉角色介绍区块头下那条琥珀发丝线（`.profile-body` 的 `border-top` + `padding-top`）：
  它同样是「接在标题下的装饰线」，标题放大后读作标题下划线，也会和换册细线抢线型语义。

## Alternatives considered

- **保留花饰，只调尺寸 / 颜色 / 频率**：形态问题不在大小。再淡就在 1x 屏消失，再亮就抢标题；
  频率已经降到单页 ≤2，说明重复出现的节拍作用本来就不成立。
- **每个区块头都画一条齐版心细线**（把区块头做成「分录行」，边界线统一在最上方）：
  结构最清楚，但 9 条全宽线会把密集数据页读成一张填满的表格，且正好回到 0018 否掉的
  「边界与内容收尾线成对」的老路。1440 全页试过：页面整体从「档案」滑向「表单」。
- **换册处改用色带（tone step）代替细线**：更软、更当代，但只在 2 处出现的满宽色块读作来路不明的
  框，且与纸纹面色的拼接处有一条硬边；本站其余层面没有任何「带」，它是第三种语汇。
- **什么都不留，换册只靠加大的留白**：157 与 112 的差只剩 45px，分级读不出来——0024 的三档分档
  会退化成空话。
- **去掉编号，只留标题 + 英文码**：编号是页内锚点与左侧索引的同源记号（`00`–`09` 与现有导航一致），
  去掉后区块头与索引脱钩。

## Consequences

- 收益：移除一件与定位不符的装饰；页面上唯一的「分割线」只在换册处出现，且是结构线而非饰件；
  标题层级从 1.6× 提到 2.4×，快速滚动时可辨；首页与详情页共用同一套更简单的头部语法
  （首页不再需要 `--section-gap` 覆写，`.banners` 只剩底部节奏）。
- 代价：常规边界完全靠留白与字号，短页与窄屏上的「区块感」比带线方案弱（≤390 时留白退回
  `--space-section` 的下限档）；`--fs-section` 是新增令牌，新消费方应直接用它而不是裸 px。
- 遗留缺口：「换册选点是否正确」仍是视觉判断，自动化守不住（同 0024）；`composition-audit` 只守
  「非 seam 头部无上边线 / seam 头部有 1px solid 上边线 / 头部内无 `.leader` 与 `.section-mark` /
  h2 ≥25px / 单页 seam ≤2」，守不住留白与字号是否读得出来。
